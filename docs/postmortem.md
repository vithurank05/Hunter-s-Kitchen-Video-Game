# Personal development notes

Write these yourself as work progresses. This file intentionally contains prompts, not an AI-written argument.

- What did I build and personally verify this week?
- Which code did I change, and why?
- What bug did I observe? How did I reproduce and fix it?
- Which design trade-off did I make?
- What did a real player find confusing?
- What would I cut or improve next?

For the final postmortem, use your own observations and wording. Record AI help in ATTRIBUTION.md.
