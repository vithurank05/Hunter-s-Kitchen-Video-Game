# Campus Café

A planned 2D café game for CSCI 4160U. Students place orders; the player assembles the food, charges the menu total, and serves them before they leave.

## Current status
Checkpoint 1 documentation and repository structure. **There is no runnable game yet.** The intended language is Odin with Raylib for desktop; build and run commands will be added when the first playable version exists.

## Repository guide
- `docs/gdd.md` — working game design document and ranked scope.
- `docs/postmortem.md` — notes to develop into the final postmortem.
- `src/` — Odin game source when implementation starts.
- `assets/` — sprites, sounds, and fonts used by the game.
- `data/` — menu and tuning data when implemented.
- `ATTRIBUTION.md` — AI assistance and asset credits; update as work continues.
